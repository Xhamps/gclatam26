# Gemini para Desenvolvedores Go

Workshop na GopherCon LATAM 2026.

## Estrutura do Workshop

### Parte 1: A Familia de Modelos Gemini
* Modelos: Gemini 3.7 Flash, Nano Banana 2 Lite, Veo, Lyria 3, Gemma
* Features: Thinking Mode, Function Calling, Grounding, Structured Outputs
* APIs: GenerateContent, Interactions, Live, Batch, Managed Agents
* Pratica 1: "Hello World" com Go GenAI SDK (`parte1-gemini`)

### Parte 2: Desenvolvimento com Gemini e Antigravity
* Ecossistema Antigravity: Antigravity 2.0, CLI (`agy`), IDE e SDK
* Customizacoes: Regras, MCP, Skills, Hooks, Plugins e Sidecars
* Pratica 2: Microserviço de geração de trilha sonora com Lyria 3 e deploy no Cloud Run (`parte2-antigravity`)

### Parte 3: GopherCon LATAM Mini Game Jam
* Formato: Hackathon 2D com Ebitengine v2 e Antigravity
* Submissao: Fork + Pull Request (`parte3-mini-game-jam`)

## Estrutura do Repositorio

* `parte1-gemini/`: Pratica 1
* `parte2-antigravity/`: Pratica 2
* `parte3-mini-game-jam/`: Mini Game Jam
* `check_env.sh`: Verificação de ambiente
